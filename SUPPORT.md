## Questions and ideas

Use [GitHub Discussions](https://github.com/purelogiccode/5DO/discussions) for
questions, setup help, compatibility discussion, and feature ideas that are not yet
concrete bug reports.

## Bug reports and feature requests

Use the [issue forms](https://github.com/purelogiccode/5DO/issues/new/choose):

- **Bug report** — reproducible defects in the emulator, desktop app, CLI, or
  documentation.
- **Compatibility report** — a specific disc/BIOS result with frame counts and
  evidence.
- **Feature request** — a concrete enhancement proposal.

Include the 5DO version, OS, architecture, renderer, audio backend, exact command line
or UI steps, and a privacy-scrubbed diagnostics bundle where possible. Never attach
BIOS ROMs or game images.

## Security

Do not open a public issue for a vulnerability. Follow
[SECURITY.md](SECURITY.md) and use GitHub's private vulnerability reporting.
